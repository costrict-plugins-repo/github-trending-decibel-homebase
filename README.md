# @decibelsystems/homebase

Branch identity, conventions, and plugin protocol for the Decibel ecosystem.

## Installation

```
/plugin marketplace add decibelsystems/marketplace
/plugin install homebase@decibelsystems
```

## What's Included

- **decibel-conventions** — Tool priority, `.decibel/` directory contract, project detection, capability manifests, package discovery, integration hooks
- **decibel-verification** — Pre-completion verification checklist, evidence-before-assertions rule, sentinel integration with graceful degradation

## Philosophy

Homebase defines what a Decibel branch IS, not everything it can do. Protocol, identity, discovery, minimum shared behavior.
